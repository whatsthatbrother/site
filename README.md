# Diar F. — freelance site

All the text on the page comes from **`site.json`** — edit it on GitHub (pencil icon, then Commit changes) and the site updates in about a minute.

- `profile` — name, role, headline, intro, `available` (true / false) and `contact`:
  `email`, `whatsapp` (number with country code), `linkedin` and `upwork` (full links). Empty ones are hidden.
- `services` — `name`, `what` (one sentence) and `price` — e.g. `"from €40 / hour"`, `"€150 fixed"`, or `null` for "Ask for a price".
- `projects` — leave `[]` to hide the section, or add `{ "name": "...", "what": "...", "image": "work/photo.png", "link": "https://..." }`.
- `skills` — the list under "What I work with".

Keep the commas between blocks, and no comma after the last one.
